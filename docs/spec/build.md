# Building an instance (`pwc build`, `pwc run`)

The builder turns one exact `pwc.lock` into a native PWC executable. It never chooses versions —
the resolver did that — and it never interprets mod code: it writes a small Cargo workspace that
points at the PWC source and at immutable store directories, and lets Cargo and rustc compile.

Implemented by `crates/pwc-builder`.

## Inputs

- the lockfile (`pwc.lock`) and the store path of every package in it;
- the PWC source directory (`[pwc].source`), which must provide
  - the runtime crate at its root (package `project_watt_cubed`), exporting
    `project_watt_cubed::run(GameBuild)` and `project_watt_cubed::harness::golden_main(GameBuild)`,
  - the mod API crate at `crates/pwc-mod-api` (package `pwc-mod-api`), re-exporting `GameBuild`,
    `ModDescriptor`, `ModRegistrar`, `Mod` and the rest of the mod-facing API;
- the profile (`release` or `dev`), the target triple (host by default) and the `rustc -vV` output.

Before building, the builder checks that the PWC source's version and `pwc-mod-api` version still
match `[pwc]` in the lock, and that every package's `pwc-api` requirement accepts that API version.

## Build ID

```text
build-id = hex(SHA-256(
    "pwc-build 1\n"
    "builder <pwc-builder crate version>\n"
    "environment <lock environment>\n"
    "pwc-source <revision> <dirty-digest>\n"
    "rustc <full `rustc -vV` output, newlines replaced by ' '>\n"
    "profile <profile>\n"
    "target <target triple>\n"
))
```

`dirty-digest` describes the exact source state (`PwcSource::dirty_digest`):

- for one tree: `clean` for an unmodified git checkout, otherwise the SHA-256 of
  `git diff HEAD --binary` plus the sorted untracked, non-ignored files and their contents (outside
  git: every file, skipping `target/` and hidden entries), so two different dirty trees never share
  a build;
- when the PWC source has path dependencies outside its own tree (the sibling `../voxel-engine`),
  the SHA-256 over every such tree's path, git revision and per-tree state, so an engine commit or
  edit also changes the Build ID.

The first 32 hex digits name the directory.

## Generated workspace

```text
$XDG_CACHE_HOME/pwc/builds/<first 32 hex digits of the build id>/
├── Cargo.toml            workspace: every member listed; `resolver`, all [profile.*] and
│                         [patch.*] (paths made absolute) copied from the PWC source's
│                         Cargo.toml so builds match vanilla exactly
├── Cargo.lock            seeded once from the PWC source's Cargo.lock (then Cargo owns it)
├── mods/<crate>/Cargo.toml   one per mod/library package (bundles generate nothing)
├── bundle/               the mod bundle: gathers the selected packages
│   ├── Cargo.toml
│   └── src/lib.rs
├── instance/             the executables (package `pwc-game-instance`)
│   ├── Cargo.toml
│   └── src/bin/{pwc-game.rs,pwc-golden.rs}
├── build.toml            metadata: build id, environment, inputs, finished time, outputs
└── bin/pwc-game, bin/pwc-golden   copied from the target directory when the build succeeds
```

`mods/<crate>/Cargo.toml` (crate = the package's crate name):

```toml
[package]
name = "pwc_inventory"          # crate name; Cargo accepts underscores
version = "1.0.0"
edition = "2024"
publish = false

[lib]
path = "/home/u/.local/share/pwc/store/<hex>/src/lib.rs"

[dependencies]
pwc-mod-api = { path = "<pwc-source>/crates/pwc-mod-api" }
pwc_hotbar = { path = "../pwc_hotbar" }
```

`bundle/src/lib.rs`:

```rust
//! Generated by pwc. Do not edit.
pub const ENVIRONMENT: &str = "sha256:…";

pub fn game_build() -> pwc_mod_api::GameBuild {
    pwc_mod_api::GameBuild::new()
        .with_environment(ENVIRONMENT)
        .with_mod(pwc_mod_api::ModDescriptor {
            id: "pwc.hotbar", name: "Hotbar", version: "1.0.0",
            register: pwc_hotbar::register,
        })
        // … every kind = "mod" package, dependencies before dependents, ties by id
}
```

`instance/src/bin/pwc-game.rs`: `fn main() { project_watt_cubed::run(pwc_bundle::game_build()); }`
and `pwc-golden.rs` the same with `project_watt_cubed::harness::golden_main`.

Generated Rust and TOML string literals are escaped (non-printable-ASCII as `\u{…}`). Before
generating, the builder checks that the PWC source is the `project_watt_cubed` package with the
locked game and API versions, that every package's `pwc-api` accepts the API version and its store
manifest matches the lock, that every mod/library has `src/lib.rs`, that the lock has no dangling
dependency or cycle, and that no two ids map to the same crate name (`a.b-c` and `a.b.c` both give
`a_b_c`) or to a reserved one (`pwc_bundle`, `pwc_mod_api`, `project_watt_cubed`, …).

## Running Cargo

`cargo build --manifest-path <build>/Cargo.toml --bins -p pwc-game-instance [--release] [-j N]`,
run in the build directory with `CARGO_TARGET_DIR=$XDG_CACHE_HOME/pwc/target` (shared by every
build so unchanged crates are not recompiled), behind the configured wrapper (see filesystem.md).
Cargo's output goes to stderr, so `pwc build` prints only the executable path on stdout. An
exclusive lock on `target/.pwc-build.lock` is held while Cargo runs and the executables are
copied (atomically) into `bin/`, so concurrent builds never swap binaries.

`build.toml` records `build-id`, `environment`, the inputs (PWC source, revision, dirty digest,
rustc, profile, target, builder version), the generated and finished times and the output paths.

## Cache

If `build.toml` matches the Build ID and records a finished build, and both `bin/pwc-game` and
`bin/pwc-golden` exist, `pwc build` returns it without invoking Cargo. `pwc cache clean` deletes `builds/` and `target/` (always safe:
everything can be rebuilt from the store and the PWC source). `pwc build --force` rebuilds.

## Running

`pwc run [--instance <name>] [--golden] [--profile …] [-- <args>]` = `pwc build`, then exec
`bin/pwc-game` (or `bin/pwc-golden`, with `WATT_GOLDEN_DIR=<instance>/goldens`) with the
environment from filesystem.md, passing `<args>` through and keeping the working directory. The
executable runs behind the same wrapper as Cargo, so the game's native libraries (Vulkan, Wayland)
are found on NixOS.
