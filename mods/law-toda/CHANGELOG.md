# Changelog — pwc.law-toda

## 0.1.0

- First release. The reversible wave field: an integer displacement phase and a momentum per
  block, one tick a palindrome of exact integer shears (half kick, drift, half kick) on a torus,
  so `unstep` is the mirrored `step` and every state runs backwards bit for bit. Stiffness from
  the bond, mass from the occurrence count, a C² periodic hardening spring. Experiments and a
  bench in the physics lab. A library: it registers nothing. Requires `pwc-api ^3.1` and
  `pwc.law-core ^0.1`.
